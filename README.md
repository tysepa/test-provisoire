# DriveRwanda - Ikizamini cyo Gutwara Ibinyabiziga cy'Agateganyo (Provisoire)

Official Rwanda provisional driving license e-learning platform and practice exam simulator.

## 🚀 Features

- **Interactive Traffic Rules & Signs**: 3D Flashcards for warning, prohibition, mandatory, and priority road signs.
- **Timed Exam Simulator**: 20-question, 20-minute timed driving license theory tests (Pass mark: 16/20).
- **Free Trial Mode**: 5-question instant trial practice exam without code/payment required.
- **MoMo Pay (80 RWF per exam)**: Payment verification for MTN MoMo Pay number `0782148861`.
- **👑 Admin Management Dashboard**: 
  - MoMo Payment Verification & Access Code Generator (`EXAM-80-XXXX`).
  - Student Registration & Subscriptions manager.
  - Question Bank Uploader tool.
  - Client Comments & Q&A Response System.
- **Dark & Light Mode**: Dynamic theme switcher.
- **Multilingual**: Full support for Kinyarwanda (`rw`), English (`en`), and French (`fr`).
- **Instructor Social Hub**: Connect with founder **Tuyisunge Epaphrodis** on WhatsApp (+250 782 148 861), YouTube, Facebook, Twitter, and Email (`epamarayika@gmail.com`).

## 🛠️ Tech Stack

- **Frontend Framework**: React JS + Vite
- **Styling**: Vanilla CSS (CSS Grid, Flexbox, Glassmorphism Design Tokens)
- **State & Storage**: React Context API + LocalStorage persistence
- **Icons & Graphics**: Pure SVG vector traffic sign renderings

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone git@github.com:tysepa/test-provisoire.git

# Navigate to directory
cd test-provisoire

# Install dependencies
npm install

# Start development server
npm run dev
```
